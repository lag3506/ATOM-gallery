# ATOM — сайт творческой галереи

Сайт написан на обычных HTML, CSS и JavaScript. Python для запуска не нужен.

## Запуск
1. Распакуй архив.
2. Открой `index.html` двойным щелчком в браузере.
3. Для редактирования можно открыть папку в VS Code.

## Файлы
- `index.html` — структура страниц.
- `style.css` — красно-чёрный адаптивный дизайн.
- `script.js` — навигация, демо-регистрация/вход, галерея, поиск, фильтры, лайки и публикация изображений.
- `icon.svg` — иконка сайта.

## Важно
Это фронтенд-демоверсия. Аккаунты и работы сохраняются только в локальном браузере. Для настоящей общей галереи и защищённой регистрации нужен backend и база данных. Не используй настоящий пароль в демо.
